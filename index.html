Zotero, la source de référence

Le hub lit directement la bibliothèque publique Zotero. Une référence ajoutée ou corrigée dans Zotero apparaît au prochain chargement du hub. Les notes et les pièces jointes ne figurent pas parmi les résultats bibliographiques.

Dans la bibliothèque, plusieurs choix d’un même filtre élargissent la recherche ; les filtres différents se combinent. Le titre ouvre le DOI ou le lien du document quand il est renseigné. Le lien « Notice Zotero » permet de consulter sa fiche. L’export CSV contient les résultats filtrés.

L’analyse décrit le corpus recensé, pas toutes les recherches réalisées dans la région. Les années sont celles des documents, pas nécessairement celles du terrain. L’onglet Qualité signale les notices à contrôler ; ses alertes demandent une vérification humaine.

Ouvrir le PDF d’une archive

Lorsqu’une copie publique validée est disponible, utilisez le lien Consulter le PDF dans les résultats. Le document s’ouvre dans un nouvel onglet ou se télécharge selon le navigateur. Le lien Notice Zotero reste distinct pour consulter les informations bibliographiques.

Une copie expurgée peut être publique alors que l’original reste sous consultation encadrée aux APDS. Vérifiez les avertissements de la notice et la présentation du PDF : la copie publique peut signaler des retraits ou des pages manquantes. Une notice seule, ou une pièce jointe réservée aux membres Zotero, ne garantit pas l’accès public au fichier.

Ajouter une référence

La consultation est publique. L’ajout et la correction nécessitent des droits d’édition dans le groupe Zotero. Sans ces droits, transmettez au responsable le DOI ou le lien original, le titre, les auteurs, l’année et une courte justification du lien avec Dzanga-Sangha.

  1. Vérifier qu’elle n’est pas déjà présente. Recherchez d’abord son DOI, puis son titre et son auteur. Pour une thèse, un rapport ou un document ancien sans DOI, comparez aussi l’organisme, la date et la version.
  2. Créer la notice dans le groupe Zotero. Avec des droits d’édition, utilisez le DOI ou le Zotero Connector depuis la source originale. Pour un document sans identifiant, créez une notice du bon type : rapport, thèse, livre ou jeu de données. Un PDF seul ne remplace pas une fiche bibliographique complète.
  3. Contrôler les métadonnées. Comparez titre, auteurs, date, revue ou organisme et identifiants avec le document ou l’éditeur. Gardez une trace du lien source et de la justification de pertinence dans le champ Extra. N’inventez pas les informations manquantes.
  4. Classer et faire vérifier. Placez une proposition dans « 00 - A verifier » avec le tag STATUS:To-Review. Après vérification, attribuez les collections thématiques et les tags contrôlés, puis remplacez le statut par STATUS:Verified. Une notice qui reste incomplète doit le signaler avec STATUS:Metadata-Incomplete.

Les collections peuvent se combiner : une étude de santé des gorilles peut relever des primates et de One Health. Les rapports de gestion ou de développement et les jeux de données ont aussi leurs catégories dans le hub.

Choisir la portée et les tags

DSPA-Core
Le document utilise des observations, du terrain, des échantillons, du suivi ou des données provenant directement des Aires Protégées de Dzanga-Sangha. Une simple mention de Dzanga-Sangha ne suffit pas.
DSPA-Relevant
Le document est directement utile pour comprendre ou gérer la zone, sans données primaires APDS identifiées. Les interventions en périphérie, dont Monasao, peuvent entrer dans cette portée lorsque leur lien avec la zone est établi.
Sites, taxons et méthodes
Utilisez les tags existants avec les préfixes SITE:, TAXON: et METHOD:. Retenez les lieux réellement étudiés, les organismes concernés et les méthodes documentées ; évitez de déduire ces informations du seul titre.
Accès au document
ACCESS:Open indique une version du document publiquement consultable. Un résumé ou une page DOI seuls ne suffisent pas. ACCESS:Restricted signale un accès limité ; si l’accès reste inconnu, gardez-le à déterminer. Une copie privée reçue d’un auteur ne prouve pas un accès public.

Un document consultable en ligne n’autorise pas automatiquement sa redistribution. Pour les documents internes ou sensibles, faites vérifier les conditions de partage avant d’ajouter une copie ou un lien public.

Comment les nouvelles publications arrivent-elles ?

Le hub reflète les ajouts à Zotero, mais ne décide pas lui-même quelles publications importer. Les recherches bibliographiques et les scripts de découverte produisent des candidats : une personne vérifie leur identité, leur pertinence et les doublons avant l’import.

La recherche combine les noms des sites, les auteurs, les citations et les dépôts documentaires. OpenAlex, Crossref, Semantic Scholar, les éditeurs et les organismes de projet peuvent retrouver des documents différents. Aucun moteur ne garantit à lui seul une couverture exhaustive, en particulier pour les rapports anciens.

Pour proposer un jeu de données, ajoutez son DOI ou son lien de dépôt, les producteurs, la version, les sites couverts et les conditions d’accès. Il est référencé séparément de l’article qui l’utilise.

Ajoutez plusieurs choix dans un même filtre pour élargir la recherche. Les filtres différents se combinent. Les nombres indiquent les références compatibles avec les autres filtres.

Auteurs les plus représentés

Chaque auteur est compté une fois par document, toutes positions de signature confondues. Les éditeurs sont exclus. Les noms et prénoms sont conservés pour limiter les homonymes ; les initiales peuvent rester séparées. Ce décompte ne mesure pas l'impact scientifique.

Vérifier et compléter les notices

Un DOI absent n'est pas une erreur. Les rapports anciens et les documents d'archives peuvent être correctement identifiés sans DOI. La justification Core détectée est une trace documentaire à vérifier, pas une certification automatique. Les liens renseignés ne sont pas testés ici.
